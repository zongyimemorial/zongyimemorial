# 宗祠祠堂形象化改造

> 需求：**「宗祠设计得不够形象好看，尽量设计成与真实的宗祠形象。」**
>
> 原状：宗祠详情页由若干「色块 + emoji 挂饰」拼成，看不出建筑感，也不像一座真的祠堂。
> 改造后：**工笔彩绘风格的建筑构件层 + 中轴四段分镜**，整页读起来是一座真的三进祠堂。

## 一、改造前后对比

| 维度 | 改造前 | 改造后 |
|---|---|---|
| 表现手法 | 纯 Tailwind 色块、圆角矩形 | 纯内联 SVG 建筑构件（零外部资源） |
| 挂饰呈现 | emoji（🦁 🕯️ 🏮） | 真实构件：石狮 / 香炉 / 牌位墙 / 幡旗 / 立柱 |
| 页面结构 | 平铺卡片列表 | **中轴递进四段分镜**（山门→天井→享堂→寝堂） |
| 建筑形制 | 无此概念 | 墙面素材决定**屋面 / 门楼 / 台基**等级 |
| 工坊缩略图 | emoji 预览 | 真实构件微缩图（所见即所得） |
| 配色 | Tailwind brand 色阶 | 工笔彩绘色板（黛瓦 / 朱红 / 赭石 / 鎏金 / 青砖） |

## 二、四段分镜（中轴空间序列）

真实祠堂是**沿中轴递进**的一组建筑。页面按同一逻辑切成四段，
每段都是一个可独立渲染的「分镜」组件（`components/clan/ClanHallScene.tsx`）：

| 段 | 组件 | 建筑构件 | 对应页面位置 |
|---|---|---|---|
| ① 山门 | `SceneGate` | 重檐屋面、鸱吻、彩画额枋、金匾、门钉+铺首衔环、抱鼓石、台基踏跺 | 页面顶部（"脸面"） |
| ② 天井 | `SceneCourtyard` | 青石地面、两侧立柱（柱础/柱身/金箍/雀替/抱柱联）、双幡（祖/宗） | 主图与相册之间 |
| ③ 享堂 | `SceneMainHall` | 斗拱 11 攒、额枋 9 枚彩画、高悬匾额（刻堂号） | 献祭面板之上 |
| ④ 寝堂 | `SceneShrine` | 三间牌位墙（昭穆序）、香案、香炉/烛台/果盘 | 祭祀记录之上 |

> **设计要点**：分镜之间的顺序就是「人走进祠堂」的动线 —— 先看到门，穿过天井，
> 进主厅见匾额，最后到寝堂见牌位。这是叙事，不是装饰。

### 硬约束（勿改）

被脚本断言的文案**必须是 HTML 节点**，SVG 只负责装饰与刻字：

```
堂号「{hall.name}」 · 字辈诗 · 派语 · 献祭 · 敬奉先祖 · 祭祀记录
当前陈设 · 每次 +2 积分 · 献上上香 / 献上献花 / 献上点烛
```

匾额文字（`SceneMainHall plaqueText`）与幡旗文字（`SceneCourtyard banners`）是唯二由
SVG 承载的业务文案，因此套件里专门断言「匾额文字为 HTML 节点」以防有人把它塞进 `<text>`。

## 三、建筑构件层 `components/clan/arch/`

工笔彩绘的绘制底座，**每件都是一个纯内联 SVG，零外部资源**：

```
arch/
  palette.ts    工笔彩绘色板（黛瓦/青砖/朱红/赭石/鎏金/汉白玉/花岗岩/青铜/楠木/夯土）
  defs.tsx      共享 <defs>：渐变、砖纹、青石纹图案
  types.ts      ArchBaseProps / ArchSize（"full" | "thumb"）
  Roof.tsx        屋面（硬山/悬山/庑殿/重檐）
  Dougong.tsx     斗拱
  PillarPair.tsx  立柱对（含抱柱联）
  Door.tsx        大门（门钉 + 铺首衔环）
  Gate.tsx        门楼（随墙门/门屋/牌坊）
  Terrace.tsx     台基（无/台基/月台）
  Lantern.tsx   Censer.tsx    StoneLion.tsx   TabletWall.tsx
  BannerPair.tsx  Plaque.tsx  Halo.tsx        Altar.tsx
```

### 配色取自真实祠堂

| 材质 | 取色 | 用途 |
|---|---|---|
| 黛瓦 | `#3d4850` | 屋面 |
| 青砖 | `#7d858b` | 墙体 |
| 朱红 | `#8e2018` | 立柱 / 大门 / 楹联 |
| 赭石 | `#a8744f` | 梁枋木构（= Tailwind accent-500） |
| 鎏金 | `#d4af37` | 匾额 / 门钉 / 斗拱 |
| 花岗岩 | `#9b978c` | 石狮 / 抱鼓石 / 门枕石 |

> **石狮为什么不用汉白玉**：汉白玉 `#dfdbd1` 与宣纸底 `#f7f4ec` 几乎同色，
> 狮子会"溶"进背景里看不见。真实祠堂门前是青灰色花岗岩，比汉白玉深，才有镇门的重量感。

## 四、建筑形制参数 `lib/clan-decor.ts`

新增一层「墙面素材 → 建筑形制」的映射。**不改动任何素材 id / 名称 / 档位 / 积分**，
纯呈现层的派生参数：

```ts
export type ClanArchParams = {
  roof: "hard" | "gable" | "hip" | "double";  // 硬山/悬山/庑殿/重檐庑殿
  gate: "arch" | "post" | "paifang";          // 随墙门/门屋/牌坊
  terrace: "none" | "platform" | "moon";      // 无/台基/月台
  steps: number;
  dougong: boolean;
  railing: boolean;
};
```

| 墙面素材 | 屋面 | 门楼 | 台基 | 踏跺 | 斗拱 |
|---|---|---|---|---|---|
| 青砖墙（免费） | 硬山 | 门屋 | 台基 | 1 级 | 无 |
| 夯土墙（免费） | 硬山 | 随墙门 | 无 | 1 级 | 无 |
| 白粉墙（免费） | 悬山 | 门屋 | 月台 | 2 级 | 有 |
| 朱漆墙（300 积分） | **重檐庑殿** | **牌坊** | 月台 | 3 级 | 有 |
| 金丝楠木（订阅） | 重檐庑殿 | 门屋 | 月台 | 2 级 | 有 |
| 鎏金殿（订阅） | 重檐庑殿 | **牌坊** | 月台 | 3 级 | 有 |

前台「当前陈设」区会把形制**显性化**展示，让用户知道「这套陈设盖出了什么规格的房子」：

```
屋面：重檐庑殿   门楼：牌坊   台基：月台 · 3 级   斗拱：有
```

## 五、装修工坊：真实构件微缩图

`components/clan/ClanDecorThumb.tsx` 把每件素材渲染成**真的构件微缩图**，
而不是一个 emoji —— emoji 完全无法传达形制、比例与做工。

**关键点：墙面不画"一块颜色"，而画该墙面等级对应的一座小门楼。**
一眼就能看出「鎏金殿 = 重檐牌坊」与「夯土墙 = 随墙门」的等级差距。

尺寸策略：所有构件都是固定 `viewBox` 的 SVG，格子是固定高度（80px）。
**只给宽度会让"竖长"构件（宫灯 400×300、香炉 260×300）超出格子被裁掉**，
因此 `Thumb` 同时约束宽度与高度，以「能放进 68px 高」反推宽度。

| 槽位 | 缩略图 | 覆盖 |
|---|---|---|
| `wall` | 按形制等级画小门楼 | 6/6 |
| `ornament` | 真实挂饰构件 | 9/10（「不加挂饰」回退 emoji） |
| `floor` / `frame` / `font` | 回退 emoji | — |

> **RSC 边界**：函数不能从 Server Component 传到 Client Component，
> 因此 `DecorStudio` 新增 `renderThumb?` prop，由 `ClanDecorStudio.tsx`（`"use client"`）
> 包一层把 `clanDecorThumb` 传进去。

### 顺带修复的真实缺陷

工坊里**锁定的 premium 素材**会落进积分分支，渲染成 **「用 undefined 积分兑换」**
（premium 素材没有 `points` 字段）。已改为按档位分支：

```tsx
item.tier === "premium"
  ? <a href={premiumHref}>开通高级订阅解锁</a>
  : <button>用 {item.points} 积分兑换</button>
```

并补了对应的回归断言（见下）。

### 公网泄露复查

宗祠详情页对祭祀记录的查询**只 `select displayName`**，
`realNameSnap` / `contactSnap` 从查询层就不进前台组件的 props。
本页仅展示脱敏名号（如 `李*华`），完整实名只出现在馆主管理台。

## 七、过程中的几个教训（勿重蹈）

| 现象 | 根因 | 解法 |
|---|---|---|
| 天井渲染成 8915px 高 | `aspect-ratio` 在 flex `stretch` 下与行高互相喂养，死循环 | 整行画成**一个 `viewBox` 固定的 `<svg>`**；`Frame` 改 `shrink-0 self-start` + 显式宽度 |
| 13 个斗拱各占满一行 | flex 下 Tailwind 百分比宽度（`w-[6.2%]`）不可靠 | 同上，改单 SVG + 绝对坐标 |
| 匾额被拉满整行、文字左对齐 | `justify-center` 行里的裸 `flex` 子项 | `w-fit whitespace-nowrap` |
| 石狮只出来一只、整体右移 | 镜像变换 `translate(-300,0) scale(-1,1)` 把狮子映射到画布外 | `translate(300,0) scale(-1,1)`；用 `getBoundingClientRect` 实测两狮 x=15/356 各宽 299 验证 |
| 从 `/tmp/scene.html` 调试得出错误结论 | 静态 `renderToStaticMarkup` **没有 Tailwind 样式表**，所有 class 都是空操作 | 一律在真实 Next 应用里预览 |
| 斗拱像"锯齿" | `preserveAspectRatio="none"` 会把图形拉伸变形 | 改 `xMidYMax meet` |
