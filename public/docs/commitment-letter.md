# 纪念馆信息真实性承诺书

**宗忆堂纪念馆创建人（经办人）真实性承诺书**

本人（经办人）已知悉并承诺如下事项：

一、本人依据《网络祭祀要求》（MZ/T 173—2025）及平台建馆审核规范，就所创建的纪念馆提交的全部材料（包括但不限于逝者姓名、生卒信息、火化证明 / 死亡医学证明 / 户籍注销证明 / 法院宣告死亡判决、殡葬机构辅助证明、亲属关系证明、历史讣告、墓址照片、家族记载等）**真实、合法、有效**，不存在虚构、伪造、冒用他人信息或"活人被祭拜"等情形。

二、本人与逝者关系真实，所填经办人身份信息（姓名、身份证号、手机号）真实准确，并授权平台在合规审核范围内核验上述信息。

三、对于因年代久远等原因无法提供法定死亡证明的，本人已通过"特殊申述通道"提交替代材料与诚恳说明，并承诺在平台规定的补传期限内补齐正式材料；逾期未补齐的，本人理解并同意该纪念馆继续仅创建者可见。

四、本人深知网络空间不是法外之地。若本人提交虚假信息、冒用他人身份、建立虚假纪念馆或将健在之人设为被祭拜对象，平台有权立即驳回建馆申请、下架纪念馆、封禁账号，并由本人依法承担相应法律责任。

五、本人承诺尊重逝者及家属意愿，不发布违法违规、违背公序良俗或侵害他人合法权益的内容。
